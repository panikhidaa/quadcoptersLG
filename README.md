# Название вашего магазина — интернет-магазин квадрокоптеров и запчастей DJI

Готовый сайт интернет-магазина (HTML/CSS/JS, без сборки) — аналог `coptercrimea.ru`, адаптированный под аудиторию **Донецка**, **Луганска** и регионов ДНР, ЛНР. Полностью рабочий: каталог, корзина, оформление заказа, страницы доставки/оплаты/гарантии, формы заявок. Везде вместо реального бренда стоит подпись **«Название вашего магазина»**, а на страницах товаров — заглушка **«Тут будут ваши товары»**.

Сайт оптимизирован под поисковую систему **Яндекс** (главный приоритет) и Google: расставлены мета-теги, геотаргетинг, микроразметка Schema.org, sitemap.xml, robots.txt с директивами для Яндекса.

## Как запустить локально

Сайт — статический. Достаточно открыть `index.html` в браузере или запустить локальный сервер.

### Вариант 1. PowerShell (Windows)

```powershell
cd drone-shop
python -m http.server 8000
```

Откройте `http://localhost:8000/`.

### Вариант 2. Node.js (если установлен)

```bash
cd drone-shop
npx serve .
```

### Вариант 3. VS Code

Установите расширение **Live Server** → правый клик по `index.html` → **Open with Live Server**.

## Как развернуть на хостинге

Любой хостинг со статическими файлами:

- **Хостинг с PHP / nginx / Apache** — просто залейте папку `drone-shop` в корень сайта;
- **Beget, Reg.ru, Timeweb, Sprinthost** — через FTP/Файловый менеджер;
- **Бесплатно — GitHub Pages, Netlify, Vercel, Cloudflare Pages**.

После загрузки откройте `https://ваш-домен.ру/` — сайт должен работать.

## Что нужно поменять перед публикацией

### 1. Название магазина и контакты

В каждом HTML-файле замените (можно поиском по проекту):

| `+7 (000) 000-00-00` и `+70000000000` | Ваш телефон |
| `info@example.ru` | Ваш e-mail |
| `https://example.ru` | Ваш домен (в meta, sitemap, robots) |
| Адреса в `contacts.html` | Ваши реальные адреса |

### 2. Логотип и фавикон

- Замените `assets/img/favicon.svg` на свой;
- Можно добавить PNG-логотип и подключить его в шапке вместо SVG-иконки.

### 3. Открытие графа (OG-image)

Поместите изображение `1200×630px` в `assets/img/og.jpg` — оно используется при шеринге сайта в соцсетях и мессенджерах.

### 4. Замените домен `example.ru` на свой

Файлы, где нужно заменить домен:
- `index.html` и все остальные `.html` — в `<link rel="canonical">`, `og:url`, JSON-LD;
- `robots.txt` — директивы `Host:` и `Sitemap:`;
- `sitemap.xml` — все `<loc>`.

Удобно сделать массовой заменой в редакторе (VS Code: `Ctrl+Shift+H`).

## SEO под Яндекс — что уже настроено

### Мета-теги

- `title` и `description` для каждой страницы с ключевыми словами **Донецк / Луганск / ДНР / ЛНР**;
- `keywords` — для Яндекса важны (в отличие от Google);
- `geo.region`, `geo.placename`, `geo.position`, `ICBM` — региональная привязка;
- `<html lang="ru">` — язык контента;
- `robots`, `yandex`, `googlebot` — отдельные директивы для разных роботов;
- `<link rel="canonical">` — на каждой странице, защита от дублей;
- Open Graph + Twitter Cards.

### Микроразметка Schema.org (JSON-LD)

На главной — `Organization`, `LocalBusiness`, `WebSite` с поисковой строкой.
На внутренних страницах — `BreadcrumbList`.
На странице ремонта — `Service`.
Когда добавите товары, добавьте на их карточки разметку `Product` с `offers.price`, `offers.availability`, `aggregateRating`.

### Файлы

- `robots.txt` — с директивой `Host:` (важно для Яндекса) и `Clean-param` (убирает дубли по UTM-меткам);
- `sitemap.xml` — карта сайта со всеми категориями;
- `manifest.webmanifest` — для PWA и улучшения поведения на мобильных.

### Тексты на страницах

- SEO-блоки с естественным вхождением фраз «купить квадрокоптер Донецк», «запчасти DJI Луганск», «доставка ДНР / ЛНР» и т.д.;
- Перечень городов доставки в футере и на странице доставки — упоминаются Макеевка, Горловка, Алчевск, Стаханов, Краснодон и другие;
- Названия моделей DJI (Mavic 3 / 4 Pro, Mini 3 / 4 / 5 Pro, Air 3 / 3S, Avata 2, FPV, Neo, Phantom 4) — соответствуют актуальной выдаче Яндекса.

## Что ещё нужно сделать для попадания в ТОП Яндекса по Донецку и Луганску

Технически сайт уже готов. Дальше — **обязательные шаги для попадания в ТОП**:

### 1. Яндекс.Вебмастер (обязательно)

1. Зарегистрируйте сайт в [Яндекс.Вебмастере](https://webmaster.yandex.ru/);
2. Подтвердите права — вставьте код подтверждения в `<meta name="yandex-verification" content="...">` (в `index.html` уже есть плейсхолдер `ВАШ_КОД_ЯНДЕКС_ВЕБМАСТЕРА`);
3. Отправьте `sitemap.xml`;
4. В разделе **Региональность** → укажите регионы: **Донецк** и **Луганск**. Это критично — без указания региона сайт не будет показываться в локальной выдаче.

### 2. Яндекс.Бизнес (обязательно)

1. Создайте профиль вашего магазина в [Яндекс.Бизнес](https://yandex.ru/sprav/) для Донецка и отдельный — для Луганска;
2. Заполните: название, телефон, адрес, часы работы, фотографии, категории «Магазин электроники», «Магазин дронов»;
3. Свяжите Яндекс.Бизнес с вашим сайтом — это даст метку на карте, отзывы и попадание в блок «Яндекс.Карты» в выдаче;
4. Просите клиентов оставлять отзывы — это сильный фактор ранжирования в локальной выдаче.

### 3. Яндекс.Метрика (обязательно)

1. Создайте счётчик в [Яндекс.Метрике](https://metrika.yandex.ru/);
2. В `index.html` есть закомментированный код метрики — раскомментируйте и замените `XXXXXXXX` на ваш номер счётчика;
3. Включите вебвизор и карту кликов;
4. Скопируйте код во все остальные `.html` файлы (можно автоматизировать через хостинг или поставить общий include на сервере).

### 4. Контент

- Заполните каталог реальными товарами с уникальными описаниями (минимум 500–1000 знаков на товар);
- На каждый товар добавьте `Product`-микроразметку;
- Создайте блог / новости с полезными статьями («Как выбрать квадрокоптер в Донецке», «Что делать, если упал DJI Mavic», «Куда можно летать на дроне в ДНР» и т.п.) — это даёт длинный хвост запросов;
- Загрузите оригинальные фото товаров со склада с подписями (alt-тегами).

### 5. Скорость и техника

- Подключите HTTPS (бесплатно через Let's Encrypt);
- Включите Gzip / Brotli сжатие на хостинге;
- Используйте CDN или хостинг с серверами в России для скорости в Донецке/Луганске;
- Оптимизируйте картинки (формат WebP, размер < 200 КБ);
- Включите кэширование статики (`Cache-Control: max-age=31536000` для CSS/JS/IMG).

### 6. Внешние ссылки и упоминания

- Региональные каталоги: 2ГИС (Донецк, Луганск), Zoon, Flamp;
- Тематические форумы по квадрокоптерам;
- Местные группы ВК и Telegram-каналы Донецка и Луганска (обзоры, ссылки);
- Реклама в Яндекс.Директе по геозапросам — параллельно с SEO даёт быстрые продажи и поведенческие сигналы для SEO.

### 7. Поведенческие факторы

- Сделайте быстрый и удобный сайт (текущий проект уже соответствует — адаптивная вёрстка, быстрая загрузка);
- Подключите онлайн-чат (Jivo / Webim) — это уменьшит отказы;
- Добавьте отзывы покупателей на сайт (можно подгружать с Яндекс.Карт через виджет);
- Отслеживайте поведение в метрике, дорабатывайте слабые страницы.

## Как добавить товары

Текущая версия — без CMS. Чтобы добавить товары, есть три пути:

### Простой путь — ручное добавление

В страницах каталога замените блок `.product-placeholder` на сетку карточек. Пример карточки:

```html
<div class="product-card">
    <img src="/assets/img/products/mavic-3-pro.jpg" alt="DJI Mavic 3 Pro">
    <h3>DJI Mavic 3 Pro</h3>
    <p class="price">189 000 ₽</p>
    <button class="btn btn--primary"
            data-add-to-cart='{"id":"mavic-3-pro","title":"DJI Mavic 3 Pro","price":189000}'>
        В корзину
    </button>
</div>
```

Кнопка «В корзину» уже работает через `assets/js/main.js`.

### Средний путь — JSON-каталог

Создайте `assets/js/products.json` и сделайте рендер карточек скриптом — добавление товара = редактирование JSON.

### Лучший путь — поставить CMS

Если планируете много товаров и регулярные обновления:
- **WordPress + WooCommerce** — самый популярный вариант, легко найти разработчика в Донецке/Луганске;
- **OpenCart 3 / 4** — хорошо подходит для российских магазинов;
- **CS-Cart** — мощный российский движок;
- **Tilda + Магазин** — без программирования, если магазин небольшой.

При переходе на CMS — сохраните URL-структуру (`/catalog/`, `/catalog/kvadrokoptery-dji.html` и т.д.), чтобы не потерять SEO-позиции.

## Технические детали

- **Без сборщика и без зависимостей** — чистый HTML, CSS, JS;
- **Адаптивно** — корректно работает на мобильных, планшетах и десктопе;
- **Корзина** хранится в `localStorage` браузера — клиент может вернуться через час и его товары не пропадут;
- **Формы** (заказ, ремонт, обратная связь) сейчас работают как демо. Для приёма реальных заявок:
  - подключите бэкенд (PHP / Node / Python);
  - или подключите сервис форм: Formspree, Getform, FormSubmit;
  - или подключите интеграцию с CRM (amoCRM, Битрикс24) через их webhook.
